# Changelog — Batch 3: Android `ownedKeys` ↔ registry drift gate (2026-05-03)

## Summary

- **What changed:** Added **`tools/check-android-owned-keys-list.py`** so **`ownedKeys`** in **`ConfigStore.loadFromJson`** (`android/.../ConfigStore.kt`) cannot drift from **`docs/config-registry.json`** (except explicit Android-only / legacy keys). Wired into **`tools/run-repo-sanity.py`** / CI **repo-sanity**.
- **Why:** **`ownedKeys`** defines which root JSON keys Android strips before **`preservedUnknownRootJson`**; a typo or stale name silently breaks merge semantics for Desktop-imported configs.
