# Changelog — Batch 0: Repo trust and verification repair (2026-05-03)

This file records **Batch 0** work: lint and test stability, repository hygiene,
documentation for local verification and signing, and donor-tree policy. It is
a **maintainer / audit** changelog; user-facing release notes may still live in
`docs/RELEASE_NOTES.md` and per-tag `docs/changelog/v*.md` when present.

---

## Summary

- **What changed:** Fixed Clippy release-gate issues (root desktop UI + `tunnel-node`), hardened `tunnel-node` UDP path error propagation, sped up and clarified `tools/check-repo-cleanliness.py` (archive pruning, donor reference roots, extra cache skips), removed committed donor binary and oversized rules snapshot from the Nova mirror, documented Android signing policy, workspace garbage collection, and PowerShell verification paths; stubbed donor `rules/` with a README.
- **Why:** CI treats Clippy warnings as errors (`-D warnings`); `tunnel-node` had a compile error blocking Clippy; the cleanliness checker could time out or fail on third-party trees; signing and release-notification authority needed a single documented story.
