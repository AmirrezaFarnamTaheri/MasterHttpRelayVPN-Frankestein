# Tooling Source Map

This map answers: "What protects this document from drift?" It lists the
high-risk docs and contracts that are generated by, checked by, or tightly
coupled to maintainer tooling.

The machine-readable source is
[`docs/tooling-source-map.json`](tooling-source-map.json), guarded by
`tools/check-tooling-source-map.py`.

## Rules

- If a mapped source file changes, run the listed generator or guard.
- If a mapped document changes, run the listed guard and the relevant
  verification profile.
- If a new generated or contract-like document is added, add it to this map in
  the same batch.
- Do not create a second source of truth. Generated docs should name their JSON
  or Rust source; hand-written contracts should name the guard that keeps them
  aligned.

## Closeout Use

When closing a batch, scan this map for touched docs and sources. If any row
matches, run the row's guard/generator and record it in the changelog and
roadmap verification notes.
